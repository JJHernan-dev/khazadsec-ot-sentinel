# KhazadSec OT Sentinel

Laboratorio didáctico de análisis de riesgos en un entorno IT/OT ficticio.

## Objetivo

Inventariar activos, describir comunicaciones y desarrollar un analizador
basado en reglas explícitas para identificar condiciones de riesgo.

## Escenario

Erebor Energy es una instalación ficticia creada exclusivamente para este proyecto.
Los activos, las comunicaciones y sus propiedades son datos de ejemplo.

<img src="img/diagrama_activos.png"/>

## Estructura

- `data/`: inventario y comunicaciones en formato CSV.
- `src/`: código Python del analizador.
- `reports/`: informes generados.

## Estado del proyecto

Fase inicial: diseño y preparación de los datos de ejemplo.

## Limitaciones

Este laboratorio no realiza pruebas sobre sistemas reales ni demuestra
el estado de seguridad de una instalación industrial. Los resultados
futuros dependerán de los datos de entrada y de las reglas definidas.
